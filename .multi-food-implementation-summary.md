## 🔌 API Integration

The components integrate with these endpoints:

### Expected Backend Endpoints
- `POST /api/v1/logs/batch` - Submit batch of food logs
  ```json
  {
    "entries": [
      {
        "food_id": 123,
        "quantity": 100,
        "meal_id": 1
      }
    ],
    "logged_at": "2026-02-09T12:00:00Z"
  }
  ```

- `POST /api/v1/foods/resolve` - Resolve natural language food input
  ```json
  { "text": "1 banana" }
  ```

- `GET /api/v1/foods/search?q={query}` - Search for foods
  (Used in FoodRow edit → search flow)

### Agent Tool Integration
When backend sends `show_confirmation_form` with:
```json
{
  "form_type": "multi_food_confirmation",
  "data": {
    "food_items": [...],
    "guessed_meal": "Breakfast",
    "overall_confidence": 0.85
  }
}
```

The FormModal will render MultiFoodForm automatically.

## 📋 Data Flow

1. **User types**: "I had 2 eggs and toast"
2. **Agent calls** `resolve_foods_nl`
3. **Backend returns** `MultiFoodConfirmationResponse`
4. **Agent triggers** `show_confirmation_form`
5. **Frontend renders** `MultiFoodForm`
6. **User edits** (all client-side):
   - Change food selection → update local state
   - Edit quantity → QuantityEditor, update state
   - Delete item → remove from state
   - Add item → call `/foods/resolve`, append
7. **User clicks** ✔️ Log Foods
8. **Frontend calls** `POST /api/v1/logs/batch`
9. **On success** → dismiss form, reset state
10. **On error** → show error, keep form open
